# 🧩 Blue Skynet IT Operations Career Path: From Help Desk to Systems Engineer

*A Blue Skynet internal training story following the career of Alex Ramirez, who begins as a Tier 1 Help Desk Technician and advances to Systems Engineer through technical skill, automation, and security-minded innovation.*

---

## 🎬 Project Overview

After the success of Blue Skynet’s Security Operations Center (SOC) initiative, the company expands its internal IT department to strengthen infrastructure and end-user support.  
To build resilience from the ground up, Blue Skynet launches the **IT Operations Career Path Program**, designed to develop IT professionals from Tier 1 Help Desk roles into full Systems Engineers.

This project documents that journey—each tier representing both a **technical lab** and a **career milestone**.

---

## 🧠 Learning Objectives

Through this multi-tier project, you’ll demonstrate:

- End-to-end understanding of **IT support and escalation workflows**
- Practical troubleshooting, automation, and system administration
- Use of enterprise tools like **OS Ticket**, **PowerShell**, **Intune**, **Active Directory**, and **Azure**
- Documentation discipline, communication, and security awareness
- How IT and Security teams collaborate inside the **Blue Skynet ecosystem**

---

## 🏢 Storyline: Meet Alex Ramirez

> *“Blue Skynet hired me as a Help Desk Technician, but I wanted to understand how the entire system works—from fixing user logins to building secure hybrid networks.”*  
> — *Alex Ramirez, Blue Skynet IT Operations*

Alex’s story unfolds over four promotion stages:

| Tier | Title | Role Description | Key Skills |
|------|--------|------------------|-------------|
| **Tier 1** | The First Week on the Help Desk | Handles user tickets, builds communication habits, learns OS Ticket. | Ticketing, password resets, VPN troubleshooting |
| **Tier 2** | The Escalation Specialist | Automates repetitive tasks, supports workstation imaging. | PowerShell, GPO, Intune, Event Viewer |
| **Tier 3** | The System Administrator | Manages servers, user access, and patch cycles. | Active Directory, WSUS, file permissions, backups |
| **Tier 4** | The Systems Engineer | Leads modernization and cloud migration efforts. | Azure AD Connect, Terraform/Bicep, Sentinel, automation |

## 🧩 Tier 1: Help Desk Technician — “The First Week at Blue Skynet”

**Scenario:**  
Alex joins the IT Support team. Users are submitting tickets about password resets, VPN access, and printer connectivity.

**Objectives:**
- Deploy and configure **OS Ticket** for internal use.  
- Create mock tickets simulating end-user issues.  
- Perform basic troubleshooting and resolution.  

**Tools Used:**  
OS Ticket | PowerShell | Microsoft 365 Admin | Remote Desktop  

**Example Tickets:**  
1. *User cannot connect to VPN*  
2. *Outlook MFA prompt failing*  
3. *Shared printer not found*

## ⚙️ Tier 2: Desktop Support / Systems Support — “The Escalation Specialist”

**Scenario:**  
With growing ticket volume, Alex starts automating repetitive tasks and resolving deeper Windows issues.

**Objectives:**
- Write PowerShell scripts for user provisioning and mapped drives.  
- Troubleshoot failed GPO applications.  
- Deploy policies through Intune.  

**Tools Used:**  
PowerShell | Intune | Group Policy Editor | Event Viewer  

**Example Lab:**  
- Automate drive mapping for department shares.  
- Resolve logon script failures through GPO.  

**Screenshots:**  
`/screenshots/tier2-powershell-script.png`  
`/screenshots/tier2-gpo-troubleshoot.png`  

**Skills Gained:**  
Automation • MDM • System imaging • Advanced troubleshooting  

**Promotion Memo:**  
> *“Alex Ramirez is promoted to System Administrator for proactively automating processes and reducing ticket resolution time by 40%.”*

---

## 🧱 Tier 3: System Administrator — “Guarding the Network”

**Scenario:**  
Alex now oversees server maintenance, backups, and security patching for Blue Skynet’s production environment.

**Objectives:**
- Build and configure an **Active Directory Domain Controller**.  
- Implement file-share permissions and WSUS patch management.  
- Configure automated backups for critical systems.  

**Tools Used:**  
Windows Server | ADUC | WSUS | Task Scheduler | Azure VMs  

**Example Lab:**  
- Create domain users, OUs, and GPOs.  
- Configure NTFS vs share permissions.  

**Screenshots:**  
`/screenshots/tier3-aduc.png`  
`/screenshots/tier3-wsus.png`  

**Skills Gained:**  
Server administration • User access control • Patching • Backup strategy  

**Promotion Memo:**  
> *“Recognized for operational excellence, Alex is promoted to Systems Engineer to lead Blue Skynet’s cloud transformation initiative.”*

---

## ☁️ Tier 4: Systems Engineer — “Modernizing Blue Skynet”

**Scenario:**  
Alex leads a hybrid-cloud project integrating on-prem servers with Azure. The goal: improve scalability and security posture.

**Objectives:**
- Configure **Azure AD Connect** for hybrid identity.  
- Deploy resources using **Bicep / Terraform IaC**.  
- Set up centralized monitoring with **Azure Sentinel + Monitor**.  
- Automate user onboarding via **Logic Apps + PowerShell**.  

**Tools Used:**  
Azure Portal | Bicep / Terraform | Sentinel | Logic Apps | Key Vault  

**Screenshots:**  
`/screenshots/tier4-azure-architecture.png`  
`/screenshots/tier4-sentinel-detection.png`  

**Skills Gained:**  
Infrastructure as Code • Cloud security • Automation • Monitoring  

**Final Memo:**  
> *“Alex’s dedication to security, automation, and cloud innovation has earned him the title of Systems Engineer — the highest technical honor within Blue Skynet IT Operations.”*
